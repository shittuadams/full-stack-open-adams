### Diagram depicting the situation where the user goes to the single-page app version of the notes app at https://studies.cs.helsinki.fi/exampleapp/spa.

```mermaid

sequenceDiagram
participant browser
participant server

browser->>server: Get /exampleapp/spa
activate server
server-->>browser: HTML Document
deactivate server

browser->>server: Get /exampleapp/main.css
activate server
server-->>browser: the css file
deactivate server

browser->>server: Get /exampleapp/spa.js
activate server
server-->>browser: the Javascript file
deactivate server

browser->>server: Get browser->>server: Get /exampleapp/spa.js
activate server
server-->>browser: [{content: "HTML is easy", date: "2019-05-23T17:30:31.098Z"},…]
deactivate server
Note right of browser: Javascript request to the notes data

Note right of browser: The browser executes spa.js, which fetches the notes data as JSON.


```
